# V2.5.6 — Service CTA & Blog Publishing

## What changed
1. All service-card CTAs are filled brand-green. No special middle-card treatment.
2. Blog headings no longer reserve 90px, nor excerpts reserve 70px. Compact vertical spacing at desktop and mobile; bottom links align via flex layout.
3. The homepage Blog lists up to 3 articles initially. When there are 4+ posts, a `View more articles` button loads three additional items per activation. It switches to `Show fewer articles` when all posts are visible. For 1–3 posts this button is hidden.
4. Read More opens `article.html`, showing cover, title, metadata, excerpt and editable long-form paragraphs, with TH/EN language buttons and links back to the Blog.

## Add article #4, #5, #6 ...
- Open `tools/site-manager.html` → `Blog`.
- Click `＋ เพิ่มรายการ blogs`. A stable id is generated automatically for the new entry. Keep it unchanged after publishing if using links externally.
- Fill English and Thai independently using the language toggle: Title, Author / Date, Excerpt, Full Article Body, Image. Separate paragraphs in the body with a blank line.
- Use `Image Assets` to replace article image assets as needed.
- Export Changes ZIP, replace `data/site-data.js` and any modified image files in the *complete* project, and upload to your hosting.
- The new `article.html` and `src/scripts/article-page.js`, `src/styles/12-article.css`, `src/styles/12-blog-upgrade.css` must remain in the deployed project.

## Architecture / limits
- Source data: `data/site-data.js`, `blogs[]` objects. Fields: `id` (immutable), `title`, `meta`, `text`, `body`, `image`, `translations.th.{title,meta,text,body}`.
- `i18n.normalize` adds fallback stable IDs to old V2.5 drafts lacking an `id`.
- Client-side article URLs use a query string. Do not assume SEO canonical/hreflang for every article; a server routing strategy can follow in production.
- Content is local/static and requires Export → commit/deploy. No CMS backend is newly connected by this patch.
- Demo article bodies are editorial placeholders only, not validated marketing statements.

- Editor Preview: article links include `editorPreview=1`; `article.html` can read `pc-v22-site-draft` from localStorage for in-browser preview. Public links never read that draft. If you edited text very recently, wait for the draft status to say saved before opening Read More.
