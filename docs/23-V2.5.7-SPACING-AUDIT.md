# V2.5.7 — Spacing System & Design Decision Log

## Design decision

The V2.5.6 landing page is visually airy, but some section padding is disproportionately large. Examples: Services 145 px above and 112 px below; Team 100 px above and 125 px below; Blog 75 px above and 110 px below. On mobile, long three-column content stacks naturally, magnifying vertical whitespace.

**Decision:** Tune to a compact-premium editorial rhythm, not an everywhere-equal padding value. Preserve separation between section title, explanatory copy, content block and following section. Keep pricing cards and the Hero's text/CTA/dots legible. Do not remove service/team/blog content to artificially shorten the page.

## How to edit

- **Global spacing:** In `tools/site-manager.html`, go to Typography & Spacing and change `Section Spacing (px)`. The dynamic CSS token `--section-space` (95px default) feeds the responsive percentages in `src/styles/13-spacing-system.css`.
- **Per-section spacing:** Edit `.services`, `.team-section`, `.blog-section`, `.pricing-section`, etc. in `src/styles/13-spacing-system.css`. Do not edit earlier duplicated `.section` rules unless you have a deliberate need.
- **Heading typography:** `.section-intro`, `.section-intro--border`, and the dedicated `html[lang="th"]` text rules are grouped in the same file.
- **Blog cards:** `12-blog-upgrade.css` continues to handle Read More and article expansion. `13-spacing-system.css` only adjusts geometry.
- **Article reader:** Additional long-form spacing refinements are appended to `12-article.css` and loaded through versioned `article.html`.

## Guardrails and outstanding risks

- No breaking changes to the public layout modules, backend code, data schema, or application behavior.
- Do not reduce fixed paragraph font sizes below readability targets to force the page to be shorter.
- The interactive Business Dashboard and Connected RFQ stack retain V2.5.6's status. Live API, mail sending, authenticated access, and real-device deployment are separate workstreams.
- Existing demo cleaning imagery and example business content are reference-only and should be replaced for commercial use where appropriate.
