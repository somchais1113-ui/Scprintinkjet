# SCWORK V1.4.1 — CTA Color Standard

**Owner-approved exact background:** `#FF6900` (RGB 255,105,0).

**Text:** Navy `#061B3D` on primary CTAs for legibility. Approximate WCAG contrast: 5.90:1; white type would be 2.89:1 and not meet normal-text AA contrast. Buttons retain dark navy text even on hover/keyboard focus, and the background hue stays `#FF6900`.

## Single source of truth

- `src/styles/18-cta-standard.css` standardizes all primary CTA components.
- `data/site-data.js` → `design.primary` defaults to `#FF6900`.
- `src/scripts/site-runtime.js` derives `--color-cta` from the current design primary to keep Website Manager preview updates functional.
- Tools that don't load the main site data use `--color-cta: #FF6900` by default.
- `tools/site-manager.html` → Design Tokens → `CTA Orange — #FF6900` changes the public-site preview and is exported with the edited site data.

## Scope

Included: Home / Header CTA, Hero, all service cards, pricing quote cards, contact form, Request Quote banners, production steps, calculator handoff, blog-more action, article quote action, RFQ continue/submit and success, Admin primary action, Quote Print, Website Manager export and Image Manager primary actions.

Excluded: secondary and outline buttons, search/language controls, destructive operations, alert/status badges, full-background navy panels, logo artwork, customer/staff imagery.

## QA

1. Start local server with `python3 -m http.server 8000`.
2. Inspect `index.html`, `pricing-calculator.html`, `request-quote.html`, `article.html`, `tools/` and all `tools/business/*.html` files.
3. Compare CSS computed `background-color` on all primary CTA selectors to `rgb(255, 105, 0)`.
4. Check long translations and mobile breakpoints, focus states and hover states.
5. If an older browser draft persists, Website Manager migrates old SCWORK CTA defaults; custom user-set palette values are intentionally preserved.

**Backend state:** unchanged. Do not accept live customer data before secure backend configuration and deployment QA.
