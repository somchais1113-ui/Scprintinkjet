# Website Transformation — Decision Log

1. Keep 2.5.7 UI layout, spacing and original greens. Rewrite public-facing business content only.
2. Use SCWork as the visible brand. This is an *illustrative storefront direction*, not evidence of a registered sticker-printing entity.
3. Preserve the existing three-item services, three-card pricing, process team and rotating application use-cases as layout components but replace their semantics.
4. Disable misleading monthly/yearly price behavior; quote each job from dimensions, material, quantity and finish.
5. Use a single RFQ journey from the service cards and CTAs; deep links can preselect `Sticker & Label` or `Large Format Inkjet`.
6. Keep backend configuration in demo mode. Do NOT show 'received' unless server actually confirms; do not accept personal data in browser demo.
7. Maintain article links and editable bilingual full-body copy.
8. Synthetic image studies are placeholders only: not actual SCWork machines, samples, staff, customer reviews or work completed.
9. Retain all older business tools and data for historical prototype compatibility; never mix demo Admin with live customer intake without an explicit migration.
