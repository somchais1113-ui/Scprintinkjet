## Manual deployment regression checklist

1. Deploy **all files** to hosting; do not replace only `index.html`.
2. Force reload the site to clear cached CSS/JS; asset query version is `2.5.5`.
3. Desktop EN/TH: check no CTA overlap, 4 small right-aligned dots, smooth Hero transition.
4. Mobile EN/TH: verify no content cut-off, scroll into sections, reduced animation if enabled in OS.
5. Inspect all 4 slide images for expected crops; change photos through the Image Manager as before.
6. Confirm Website Manager TH/EN and the RFQ/Business demo still work.
7. Before public RFQ usage, complete production backend and security deployment from V2.5 docs.
