# V2.4 — QA / Decision Log / Anti-pattern Register

## Automated status

- `npm run check` runs the original V1–V2.3 regression suite and **`qa/validate-v24.mjs`**.
- V2.4 tests validate financial arithmetic (fixed/percent discount; VAT on/off; gross-profit ex VAT), input rejection, synthetic RFQ intake, linked customer references, append-only quotation revision, stale-quote rejection, quote→order, duplicate order guard, backwards-compatible localStorage/JSON, route files and source dependencies.
- Test data is synthetic. No network calls are required to run these tests.
- Direct Chromium navigation to both HTTP localhost and file:// was blocked with `ERR_BLOCKED_BY_ADMINISTRATOR`. **As a workaround, HTML/CSS/JS were inlined into a Chromium `about:blank` test document.** In that simulated browser context, TH/EN toggling, three wizard steps, local RFQ save, builder price edits, calculation, quote save, print preview DOM rendering, mobile 390px no-overflow, and the four legacy Admin module renders all passed with no page errors. This does NOT certify the real hosted URL, filesystem/origin interactions, actual print dialogue, keyboard accessibility, or cross-browser behavior. Those remain manual QA items.

## Decisions / risks

| ID | Decision / risk | Mitigation |
|---|---|---|
| D24-01 | Preserve V2.3 store key/schema and old modules | Optional `rfq.spec`, `quote.quotation`, `netRevenue` and `taxAmount`; regression suite |
| D24-02 | No automatic supplier pricing or self-service final price | Admin must enter verified unit prices and supplier costs |
| D24-03 | Gross profit excludes VAT for V2.4 quotations | Show customer amount inc VAT separately; old V2.3 sales default to legacy amount with unknown VAT basis |
| D24-04 | New quote revisions append records | Latest-only workflow, duplicate-order guards |
| D24-05 | Protect against fake production readiness | Visible DEMO warnings on website, Admin and print document |
| R24-01 | LocalStorage is not central data or confidential | Dummy data only; production requires authenticated database |
| R24-02 | Local file picker could appear to upload | Copy explicitly says no upload; store only `fileSelected` boolean |
| R24-03 | Estimated costs omit overhead/tax/returns/reworks | Label KPI estimated; confirm cost model before quoting real jobs |
| R24-04 | Browser screenshot click QA blocked | User/manual QA checklist; deploy only after independent device validation |
| R24-05 | Legacy seed orders may use VAT-inclusive amounts | `netRevenue ?? amount`; mark tax basis unknown until migrated |
| R24-06 | Static Admin exposed publicly on GitHub Pages | Demo only; separate protected Admin application before real data |
| R24-07 | The public landing page still visually sells cleaning | RFQ beta is a separate experimental module until printing brand transformation is approved |

## Recommended production next step

Build authenticated backend and a validated RFQ submission API with protected artwork storage, role/permission model, supplier rate catalog and a real production quotation numbering policy. Do **not** put service role keys, credentials or customer PII in the static repository.
