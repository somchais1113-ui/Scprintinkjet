# SCWORK V1.4 — Brand, Contact Strip, Copy & Responsive Audit

## Header
- The public header displays the user's supplied SCWORK navy/orange mark without duplicating or attaching a machine-translated Thai tagline. The copy has been kept in the actual Hero sections instead.
- Top bar: left-side summary / right-side LINE, office phone, mobile phone, using the reference layout **without copying third-party contacts**.
- Contact values are blank until explicitly configured; blanks display as an em dash, not as a fake phone number or interactive dead link.
- Configure via `tools/site-manager.html` → `Brand & Navigation` → `Top Contact Bar & Contact Details`. Fields are shared across locales. If needed, `config/public-config.js` supplies fallback values.
- The CTA remains a Smart RFQ route rather than an email-client action.

## Color system
- SCWORK logo Orange approximately `#FC6201`; accessible CTA Orange `#C94A00`; CTA Hover `#B84300`.
- Logo Navy approximately `#012A62`; Deep footer/navigation `#061B3D`.
- Neutral ink `#082E66`, body `#5B6B84`, light blue-gray surface.
- Replaced legacy green/mint color values in public CSS, calculator, RFQ, article, admin, print quotation and Website/Image Managers; red invalid/status/error alerts and yellow caution areas remain functional safety colors where applicable.
- The original SCWORK logo PNG is supplied as a transparent high-resolution raster; no fonts are bundled.

## Copy & content
- Removed headline-adjacent duplicate/translated brand tagline from the public logo lockup; the brand description remains part of the Hero copy.
- Clarified editor color field to `Primary Orange (CTA)` and removed unused top-bar CTA text fields from the Content editor.
- SiteData remains the authoritative public copy/content export (14-language modal fallback limitations unchanged).
- Backend remains **demo/unconfigured**: do not enter real personal data until Supabase/Resend/Turnstile have been configured and tested.

## Validation guidance
- Run `npm run check`, `npm run check:pricing`, `npm run check:locales` and `npm run check:brand`.
- Visual review on desktop and mobile recommended after real deployment (hosting may cache old CSS). Use entire ZIP, not HTML only.
- The inherited `check:v25` is historical and expects a cleaning-site general inquiry link, which does not match the inkjet-specific canonical RFQ flow.
