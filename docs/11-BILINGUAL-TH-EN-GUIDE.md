# Bilingual TH / EN — คู่มือ V2.2

## แก้ข้อความแต่ละภาษา

1. เปิด `tools/site-manager.html` แล้วเลือก TH หรือ EN บริเวณมุมบนของหน้า Editor
2. เลือก Page Text, Services, Pricing, Team, Reviews หรือ Blog แล้วแก้ข้อความในภาษาที่เลือก
3. ดู Live Preview; หากเปลี่ยนเป็น TH ข้อความไทยจะไม่ทับข้อความอังกฤษ
4. เปลี่ยนภาพหรือราคาได้เหมือนเดิม: ภาพและราคาใช้ร่วมกันทั้งสองภาษา
5. กด Export Changes ZIP หลังจากแก้ไขเสร็จ และแตก Patch ทับ Project Root เดิม

## ภาษาเริ่มต้นของลูกค้า

Brand & Navigation → Language Settings → Default Website Language → เลือก `en` หรือ `th`

กรณีลูกค้าเคยกดสลับภาษา เว็บไซต์จะพยายามจำค่าจาก localStorage ของ Browser ก่อน หาก Browser ปิดกั้น Storage จะใช้ค่าเริ่มต้นโดยอัตโนมัติ นอกจากนี้ `?lang=th` และ `?lang=en` สามารถระบุภาษาในการเปิดหน้าครั้งนั้นได้

## โครงสร้างข้อมูลภาษา

`data/site-data.js` มีเนื้อหา EN เดิมไว้ตามโครงสร้าง V2.1 เพิ่ม `i18n.th` เพื่อเก็บคำแปลของส่วนที่เป็น Global/Section และเพิ่ม `translations.th` ในแต่ละ Collection Item เพื่อให้ลากหรือจัดเรียงรายการแล้วคำแปลไม่สลับกัน ราคา ตัวเลข สกุลเงิน และรูปใช้ร่วมกัน ฟังก์ชัน `resolve()` ใน `src/scripts/i18n.js` ประกอบข้อความที่จำเป็นเพื่อ Render โดยไม่แก้ข้อมูลต้นฉบับ

ถ้าคำแปลไทยว่าง ระบบจะแสดง English fallback ในช่องนั้นเพื่อหลีกเลี่ยงข้อมูลหาย ส่วน `schemaVersion` เพิ่มจาก 1 เป็น 2 และสามารถนำเข้าข้อมูลเดิมได้บางส่วนผ่าน Editor โดยควรตรวจคำแปลไทยหลัง Import เสมอ

## รายการตรวจสอบก่อนใช้งานจริง

- [ ] ตรวจถ้อยคำไทย/อังกฤษว่าตรงชื่อบริการจริง รวมทั้งความเหมาะสมของคำทางธุรกิจ
- [ ] เปลี่ยนข้อมูลติดต่อ Email, Address, Phone ของตัวอย่าง
- [ ] กำหนดราคาและนโยบายคิดค่าบริการที่ถูกต้องจริง
- [ ] ใช้รูปที่ได้รับอนุญาต และเปลี่ยนรูป AI placeholder เมื่อพร้อม
- [ ] ใช้คำรับรองจากลูกค้าจริงที่ได้รับอนุญาต
- [ ] เปิดเว็บบนมือถือจริง และตรวจ Paragraph Wrapping ภาษาไทย
- [ ] ทดสอบ Form mailto กับแอปอีเมลที่ติดตั้งบนอุปกรณ์ลูกค้า
- [ ] สำหรับ SEO 2 ภาษา แนะนำทำหน้า `/th/` + `/en/` และ hreflang ในเฟสถัดไป

## Technical note

`localStorage` อาจไม่พร้อมในบางโหมดส่วนตัว, sandbox หรือ `file://`; โค้ดมี fallback พร้อมใช้งานโดยไม่ crash. ไม่มีการส่งข้อความไป server. หมวด Design Tokens และภาพไม่ได้แยกตามภาษา; หากต้องการภาพคนละชุดต่อภาษา ให้ขยายโครงสร้างในอนาคต.
