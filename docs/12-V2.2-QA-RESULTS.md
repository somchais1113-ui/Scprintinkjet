## Known constraints

- A fully hosted browser run against localhost and file:/// URLs could not be run here: the execution sandbox blocks those navigations (ERR_BLOCKED_BY_ADMINISTRATOR). Tests used a sandboxed Chromium embedded DOM harness and a simulated iframe source; recheck on a hosted preview before production.
- Local WebP images are present in archive; they are AI-generated placeholders and NOT actual Figma source images.
- Legacy V2.1 drafts are imported with best-effort EN copy and translation fallback. Review custom Thai strings following import.
- `mailto:` form is a demo; no database, email dispatch, admin authentication or GitHub publishing is implemented.
- JS language switch does not create distinct search-indexable language URLs. Multilingual SEO routes/hreflang are a separate feature.
- Google Fonts availability depends on network; system fallback is provided.
