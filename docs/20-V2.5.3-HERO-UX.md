# ProCleaning V2.5.3 — Full-bleed hero and CTA-aligned dots

## Changes
- Removed the browser's default `<figure>` margins from all four hero slides: `margin: 0; width: 100%; height: 100%`.
- Background imagery now fills the whole Hero section edge-to-edge with `object-fit: cover` (intentional cropping at different aspect ratios).
- Reorganized the Hero into a copy block and a full-width action row. The two CTA buttons stay on the left while four pagination dots align with their vertical center on the right on desktop.
- Dots use ~7px visible circles while retaining 28px clickable targets. Active dot uses the brand green. No previous/next arrow buttons.
- On small screens, the action row can wrap rather than causing overflow; the dots remain right-aligned.
- Carousel rotation, dot selection, TH/EN, and the existing RFQ/Admin features are preserved.

## Editable images
Four hero images currently use local files, and all four are independent `<img>` elements in `index.html`:
1. `assets/images/hero/hero-scene.webp`
2. `assets/images/about/main.webp`
3. `assets/images/services/office.webp`
4. `assets/images/quote/main.webp`

Runtime also resolves some slide paths from `data/site-data.js`. If you replace assets, keep the same paths/names; alternatively change the slide image paths in `src/scripts/main.js`.

## Visual QA
Open `index.html` via a local HTTP server. At 1440, 768, and 390px, verify:
1. No blank framing on any of the four slide edges.
2. Dots render at right end of the CTA row on desktop; no arrows.
3. Dots remain accessible via keyboard focus and selection; auto-rotation remains operational.
4. TH/EN toggling does not change image geometry.
5. The customer submission and Admin tools still open as before.
