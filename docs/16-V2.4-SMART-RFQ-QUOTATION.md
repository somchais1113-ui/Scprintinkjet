## End-to-end demo workflow (one browser + one origin)

1. Serve project folder with `python3 -m http.server 8000` and open `http://localhost:8000/request-quote.html`.
2. Switch TH / EN. Choose **Sticker & Label**, fill a fictional project title, size 80 × 100 mm, quantity 500, PVC, matte lamination, select artwork readiness. Never upload actual artwork: only the selected/not-selected flag is stored. Do not enter names, contact information, emails or confidential details.
3. Review and acknowledge demo boundary. Click **Save demo RFQ**. A *synthetic* customer and RFQ record are written to localStorage. Click **Open Quotation Builder**.
4. In builder, enter selling/cost unit amounts, additional direct costs, discounts, shipping charge, optional VAT %, terms. Numbers update immediately. **Save draft** creates a new version (v1, v2, …); previous versions remain unchanged.
5. Use **Open print / Save PDF view**; in your browser print dialog choose “Save as PDF”. The printout visibly says **DEMO**. There is no actual PDF generation backend.
6. Open **RFQ & Quotations**, switch to **Quotations** tab, mark latest draft **Sent** and optionally **Confirm Order**. Open **Orders** and change its demo production state. Open **Dashboard** to see updated KPIs.
7. Export **Backup Demo JSON** from business tools before clearing browser storage. Reimport compatible JSON on the same website origin to restore data. Backups are files handled by the user, not automatically synced.

## Quotation arithmetic

**Do not mistake selling price for net revenue.** All monetary figures are illustrative, in THB, rounded to 2 decimal places. The engine is deliberately independent from the UI so formulas can be unit-tested.

```
Line subtotal          = SUM(quantity × selling unit price)
Discount               = FIXED THB or PERCENTAGE of line subtotal (capped at subtotal)
Net sales, VAT excluded= Line subtotal − Discount + Shipping charged to customer
Output VAT             = Net sales × optional VAT rate (default assumption 7%)
Customer total         = Net sales + Output VAT
Estimated direct cost  = SUM(quantity × direct unit cost) + Additional direct costs
Estimated gross profit = Net sales − Estimated direct cost
Estimated gross margin = Estimated gross profit / Net sales
```

Additional direct costs: materials, supplier/outsourcing, production labor, finishing/QC, logistics and miscellaneous direct costs. These are **internal only** and not printed in the customer quote. The engine prevents negative input, invalid percentages, non-finite values, zero-quantity items and discounts greater than 100%. A selling price of zero on a line is allowed, but the whole net quotation must be positive before saving.

**Calculation example:** 500 labels × ฿18 selling / ฿8 unit direct cost, materials extra ฿120, fixed discount ฿100, customer shipping fee ฿50, VAT 7% → subtotal ฿9,000, net sales ฿8,950, VAT ฿626.50, total ฿9,576.50, direct cost ฿4,120, estimated gross profit ฿4,830, margin 53.97%.

VAT 7% is an editable demo assumption, not tax advice; actual tax treatment, invoicing, registration, discounts and shipping taxation must be checked before commercial launch.

## Revenue, revisions and old records

- **Customer-facing quote amount** on new quotations = total **including** selected VAT. This carries to `orders.amount`.
- **Business revenue / profit base** from new quotations = `orders.netRevenue`, **excluding** VAT. The V2.4 dashboard uses `order.netRevenue ?? order.amount`, so V2.3 legacy orders remain readable but may have unknown tax treatment.
- New drafts are immutable versions; newest quote per RFQ is used for pipeline metrics. Only the latest quote can be sent/accepted/rejected.
- Order confirmation copies amount, netRevenue, taxAmount and direct cost from the confirmed quote; it blocks duplicate Order from the same RFQ.
- Order status tracking remains unchanged, and this version does **not** make an Order a payment receipt.

## Security and deployment rule

**Do not publish this as a real customer-facing RFQ or protected Admin.** Static files do not provide secret storage, access control or customer confidentiality. Business data in localStorage can be read or modified by scripts in the same origin and is tied to the browser/device; if a user clicks the RFQ demo on GitHub Pages, their entry appears **only in their own browser**—not in your Admin on a different computer. Publicly hosting `tools/` exposes the unauthenticated demo controls. `noindex` is not an access control. For a real service build authenticated server APIs + row-level authorization, upload size/type validation, malicious-file scanning, private object storage, secure client contact collection and data retention/consent controls. Restrict or remove demo Admin access before production.
