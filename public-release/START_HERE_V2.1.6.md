# SCWork V2.1.6

หน้าแรกใช้แกลเลอรี **ประเภทวัสดุที่มีให้เลือก** แทนสไลด์ตัวอย่างการใช้งานเดิม เรียงวัสดุ 5 แบบในแถวเดียวบนจอกว้าง และจัดใหม่เป็น 3 หรือ 2 คอลัมน์เมื่อจอแคบลง

1. สติกเกอร์กระดาษขาว
2. สติกเกอร์กระดาษคราฟต์
3. สติกเกอร์ PP ขาว
4. สติกเกอร์ PP ใส
5. สติกเกอร์ PVC

ภาพจำลองแบบมาโครใช้มุมลอกใกล้เคียงกัน มีปุ่มขยายทุกรูป ภาพใช้เพื่อเปรียบเทียบลักษณะผิว ไม่ใช่ตัวอย่างรับรองสเปกงานจริง

## ไฟล์ภาพ

- ไฟล์ WebP สำหรับเว็บอยู่ใน `assets/images/materials/` ขนาด 800 × 800 px
- ไฟล์ PNG ต้นฉบับภาพจำลองอยู่ใน `assets/images/source/materials/` ขนาด 1254 × 1254 px
- หากต้องการแทนด้วยภาพถ่ายจากวัสดุจริง ให้นำภาพสี่เหลี่ยมจัตุรัสมาเปลี่ยน WebP โดยใช้ชื่อเดิม

ระบบคำนวณราคา แถบช่วยเหลือมาสคอต และหน้าภายในอื่น ๆ ไม่เปลี่ยน

## เปิดและตรวจ

เปิดเว็บจากโฟลเดอร์ที่แตก ZIP ด้วย `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000/` ใช้ `npm run check:v216` ตรวจแกลเลอรี หรือใช้ `npm run build:public` เพื่อสร้างชุดลงเว็บ
