# SCWork Inkjet V2.1.1 — ปรับสัญลักษณ์บนหน้าเว็บ

ปรับข้อความและไอคอนจาก V2.1.0 โดยไม่แตะภาพ โลโก้ สูตรราคา ข้อมูลภาษี หรือระบบขอราคาและติดตามงาน

- เมนูภาษาใช้รหัสและชื่อภาษา รองรับครบ 14 ภาษาเหมือนเดิม ไม่มีธงอีโมจิ
- หน้าแรก ปุ่มติดต่อ และแถบล่างใช้ไอคอน SVG แบบสีเดียวแทนรูปโทรศัพท์หรือแชตที่มาจากตัวอักษร
- เอาเครื่องหมายตกแต่งออกจากปุ่ม หน้าเสนอราคา และข้อความสำเร็จ รวมถึงหน้ารุ่นเก่าและเครื่องมือใน Full Package
- คงเครื่องหมายที่เป็นความหมายจริง เช่น ลิขสิทธิ์ ตัวคูณ ลบ และลูกศรบอกลำดับขั้นตอน
- ภาพต้นฉบับและภาพหน้าจออ้างอิงไม่ถูกแก้ไข รอบนี้ไม่ได้เปลี่ยนภาพตาม Image Audit

ตรวจชุด Full ด้วย `npm run check:v211` และสร้าง Public ด้วย `node qa/build-public-v211.mjs ชื่อโฟลเดอร์ใหม่` ใช้เฉพาะ Public สำหรับเผยแพร่เว็บ
