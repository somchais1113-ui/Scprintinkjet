# SCWork Inkjet V2.0 — Phase 04 / ติดตามงานและสั่งซ้ำ

เพิ่มหน้าติดตามสถานะและเปิดคำขอสั่งซ้ำ โดยไม่เปลี่ยนหน้าแรก สูตรราคา Smart Quote หรือส่วนตัวอย่าง Proof เดิม ใช้ร่วมกับ Project Desk ของ V1.9

## เปิดทดสอบ

แตก ZIP แล้วรัน `python3 -m http.server 8000` จากโฟลเดอร์ที่มี `index.html`

- ลูกค้าเข้า `http://localhost:8000/order-tracking.html` หรือกด “ติดตามงานและสั่งซ้ำ” ที่ท้ายหน้าฉลากสินค้า
- ทีมงานเปิด `http://localhost:8000/tools/order-desk.html` จาก **Full Package** เท่านั้น
- เปิด `http://localhost:8000/project-quote.html?mode=reorder` เพื่อใช้ไฟล์สเปกสั่งซ้ำที่ทีมสร้าง
- รัน `npm run check:v200` ในชุด Full เพื่อตรวจเส้นทางด้วยข้อมูลจำลอง ไม่ต้องมี LINE หรือราคาอนุมัติเพื่อทดสอบส่วนนี้

## ทีมงานอัปเดตสถานะและออกลิงก์

1. เปิด Order Desk แล้วนำเข้า JSON จาก Project Desk สำหรับงานใหม่ หากเคยสร้างลิงก์แล้วให้เปิดไฟล์ **Order Desk สำรองล่าสุด** เพื่อใช้รหัสเดิมและลำดับฉบับเดิม
2. ใส่ URL ฐานของเว็บ เช่น `http://localhost:8000/` สำหรับทดสอบบนเครื่อง หรือ URL HTTPS ที่เผยแพร่จริง เลือกขั้นตอนปัจจุบันและกำหนดส่งล่าสุดที่ทีมแจ้งลูกค้าถ้ามี
3. กดดาวน์โหลดไฟล์สถานะชื่อรหัส 32 ตัวอักษรไว้ใน `order-status/` ของโฟลเดอร์ Full ตอนทดสอบบนเครื่อง หน้าเว็บจะอ่านได้ทันที สำหรับลูกค้าจริง ให้สร้างชุด Public ด้วย `node qa/build-public-v200.mjs ชื่อโฟลเดอร์ใหม่` แล้วเผยแพร่ชุดนั้นและเปิดทดสอบลิงก์ก่อนส่ง
4. คัดลอกลิงก์ที่มีรหัสต่อท้าย `#` และส่งให้ลูกค้าผ่านช่องทางโครงการ ลูกค้าเปิดดูได้โดยไม่ต้องสมัครสมาชิก ชุด Public ไม่รวมข้อมูลลูกค้าในสถานะ และไม่มีรายชื่อโครงการให้ค้น
5. ดาวน์โหลด **Order Desk JSON** ล่าสุดไปเก็บภายใน หลังออกสถานะครั้งต่อไปให้แทนไฟล์สถานะชื่อเดิมและเผยแพร่ชุด Public ใหม่ เพื่อให้ลิงก์เดิมเปิดดูสถานะใหม่ได้ ให้ผู้ประสานงานหนึ่งคนดูแลไฟล์ฉบับล่าสุดต่อหนึ่งโครงการ

สถานะแสดงเวลาที่ทีมบันทึกล่าสุด ไม่ใช่ระบบอัปเดตสด การเปิดหน้า Order Desk ไม่ได้อัปเดตเว็บไซต์เอง ถ้าต้องหยุดงานชั่วคราว ให้เลือกพักงานและเผยแพร่ฉบับใหม่ หน้าเว็บจะไม่แสดงวันส่งเดิมระหว่างพักงาน หากขอเพิกถอนลิงก์ ให้นำไฟล์รหัสนั้นออกแล้วเผยแพร่ชุดใหม่ และตรวจว่า URL เก่าจากหน้าเว็บสาธารณะไม่เปิดไฟล์ได้

ลิงก์เป็นลิงก์แบบผู้ถือรหัสเปิดดูได้ ไม่ใช่ระบบล็อกอินหรือการรับรองตัวตน อย่าใส่ชื่อผู้ติดต่อ ที่อยู่ ชื่อสินค้า ราคา ไฟล์แนบ หรือหลักฐานอนุมัติในไฟล์สถานะ ตัวสร้างชุด Public ตรวจว่าไฟล์ใน `order-status/` มีเฉพาะฟิลด์สถานะที่กำหนดและชื่อไฟล์ตรงกับรหัส หากไฟล์ผิดรูปแบบ จะไม่สร้างชุด Public

## ลูกค้าสั่งซ้ำ

1. หลังโครงการส่งมอบ ให้ทีมยืนยันชุดแบบฉบับปัจจุบันใน Project Desk ก่อนออกไฟล์สเปก ตรวจรายการ SKU กับแบบที่อนุมัติและงานที่ส่งจริง ระบุวัสดุและขนาดจริง รวมถึงการตัดหรือเคลือบถ้าต้องทำซ้ำ
2. จาก Order Desk ให้ดาวน์โหลดไฟล์ `…-repeat.json` แล้วส่งให้ลูกค้าแยกทาง LINE หรือช่องทางโครงการ **ไม่วางไฟล์นี้ในเว็บสาธารณะ** ไฟล์มีเฉพาะเลขอ้างอิงชุดแบบและข้อมูลสเปกฉลาก ไม่ดึงราคา ที่อยู่ ลิงก์ Artwork หรือหมายเหตุเดิมของโครงการไปด้วย
3. ลูกค้าเปิดไฟล์ผ่าน “สั่งซ้ำจากไฟล์สเปกของ SCWork” ไฟล์เปิดในเครื่อง ไม่อัปโหลด ลูกค้าปรับหรือลบ SKU และเปลี่ยนจำนวนได้ เมื่อกดเตรียมบรีฟ ระบบจะออกเลขโครงการใหม่และแนบเลขชุดแบบเดิมไว้ให้ทีมตรวจ
4. คัดลอกหรือดาวน์โหลดบรีฟใหม่แล้วส่งให้ทีม หากตั้ง LINE OA จริงจะเปิดร่างข้อความได้เหมือนเดิม ผู้ใช้ยังกดส่งเอง ไม่มีการสร้างคำสั่งซื้อหรือคิดราคาเดิมอัตโนมัติ ทีมยืนยันวัสดุ ราคา และวันส่งของคำขอใหม่ก่อนเริ่มงาน

## ขอบเขตแพ็กเกจ

- **Full Package** มี Order Desk, Project Desk, คู่มือและชุดทดสอบ ใช้เฉพาะภายใน
- **Public Website** มีหน้าติดตามและหน้าฝั่งลูกค้า ไม่มีไฟล์โครงการจริง ไฟล์สถานะตัวอย่าง หรือข้อมูลภายใน
- ทั้งสองชุดนี้ยังไม่ถูกเผยแพร่ ไม่ได้ตั้ง LINE OA หรือไฟล์สถานะของโครงการจริงใน ZIP ที่ส่ง
