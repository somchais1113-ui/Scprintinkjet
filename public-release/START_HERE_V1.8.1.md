# SCWork Inkjet V1.8.1 — Phase 01 / สร้างความน่าเชื่อถือ

อัปเดตเฉพาะหน้า `product-labels.html` และไฟล์ประกอบของหน้านี้ หน้าแรก แบนเนอร์เดิม ปุ่มสี `#FF6900` Smart Quote และ Pricing Master คงเดิม

## เปิดทดสอบ

แตก ZIP แล้วเปิด Terminal ในโฟลเดอร์ที่มี `product-labels.html` รัน `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000/product-labels.html` ทดสอบภาษาอังกฤษได้ที่ `http://localhost:8000/product-labels.html?lang=en`

- Full Package มีต้นฉบับ Render, โค้ด, เครื่องมือภายใน และชุดทดสอบ ใช้ `npm run check:v181` เพื่อตรวจเวอร์ชันนี้
- Public Website มีเฉพาะไฟล์หน้าลูกค้า หากแก้จาก Full Package ให้รัน `node qa/build-public-v181.mjs ชื่อโฟลเดอร์ใหม่` แล้วใช้ไฟล์ในโฟลเดอร์ใหม่เป็นชุดเผยแพร่
- หน้า Landing ยังเป็นหน้าที่เข้าด้วยลิงก์ตรง ไม่เปลี่ยนเมนูหรือหน้าแรก และยังไม่ได้เผยแพร่เว็บไซต์

## สิ่งที่ลูกค้าเห็น

ลำดับงานคือ ส่งสเปก → ตรวจไฟล์ → อนุมัติแบบ → ผลิตและส่งมอบ ตัวอย่าง Digital Print Proof แสดงขนาดฉลาก วัสดุ แนวตัด และเลขเวอร์ชัน เป็นภาพอธิบายบนเว็บ ไม่ใช่ไฟล์พร้อมพิมพ์ งานลูกค้า หรือระบบอนุมัติออนไลน์ สีบนหน้าจอไม่ใช้รับประกันสีจริง

ปุ่มเดิมพาไป Smart Quote โดยเลือกหมวดฉลากสินค้าและโหมดตามปุ่ม ไม่มีราคาใหม่ ไม่มีการสมัครสมาชิกหรืออัปโหลดไฟล์เพิ่ม เมื่อยังไม่มีเรทขายที่อนุมัติ ปุ่มหลักจะแสดง “ส่งสเปกเพื่อขอราคา” ตามเงื่อนไขเดิม

## เปิดภาพถ่าย FORM 01 หลังพิมพ์ตัวอย่างจริง

1. พิมพ์ฉลากตัวอย่างของ SCWork บน PP ขาว แล้วถ่ายแผ่นหลังพิมพ์ ขอบไดคัตระยะใกล้ และฉลากติดบนขวด ห้ามใช้ Render หรือไฟล์ลูกค้าแทนรูปทั้งสามมุม
2. เก็บภาพใน `assets/images/labels/print-sample/` ตั้งชื่อ a-z, 0-9 หรือขีดกลาง แนะนำ WebP แนวนอน 4:3 และจัดตัวอย่างสำคัญไว้กลางเฟรม
3. แก้ `data/label-evidence.js` ให้ `sheet`, `edge`, `bottle` ชี้ไปยังคนละไฟล์ แล้วตั้ง `approvedForPublication: true` เมื่อพร้อมเผยแพร่ ตัวอย่างเส้นทางอยู่ในไฟล์ตั้งค่า
4. โหลดหน้าใหม่เพื่อเช็กภาพและคำบรรยายใน TH/EN หากภาพใดหาย โหลดไม่ได้ หรือเส้นทางไม่อยู่ในโฟลเดอร์ที่กำหนด เว็บจะซ่อนทั้งส่วน ไม่โชว์กล่องว่างหรือภาพเสีย

## ตั้งช่องทางติดต่อของทีม

ใส่เบอร์หรือ LINE OA ที่ตรวจแล้วว่าเป็นช่องทางของ SCWork ใน `config/public-config.js` หน้าฉลากใช้ `officePhone`, `mobilePhone` และ `lineId` หรือ `lineUrl` โดยใช้เบอร์ไทย และ URL ของ `line.me` หรือ `lin.ee` ตามรูปแบบลิงก์ติดต่อ ถ้ายังไม่ตั้งค่า จะไม่แสดงปุ่มติดต่อในส่วนท้าย ควรลองกดลิงก์จริงจากมือถือก่อนเผยแพร่
