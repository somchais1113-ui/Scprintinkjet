# SCWork V2.1.2

## ปรับเฉพาะหน้าแรก

- ตัดบล็อก “มีงานสติกเกอร์ที่อยากผลิตใช่ไหม?” พร้อมภาพสองใบในบล็อกออกจากหน้าจอ โดยเก็บไฟล์ภาพไว้ครบ
- ย้ายการ์ด “เลือกแนวทางผลิตให้เหมาะกับงาน” มาแทนแถบ “เตรียมสเปกก่อนสั่งพิมพ์” ถัดจากบริการและก่อนขั้นตอนการผลิต
- ขยายข้อความรายการย่อยทั้งสามการ์ดเป็น 18–21 px และปรับระยะบรรทัดเมื่อข้อความตัดบรรทัดบนจอเล็ก
- คงลิงก์เครื่องคำนวณราคาและประเภทงานที่ส่งต่อจากแต่ละการ์ด รวมถึงสูตรราคาและหน้าอื่นทั้งหมด

## เปิดทดสอบ

ใช้โฟลเดอร์ที่แตกไฟล์แล้วรัน `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000/`

- Public Website สำหรับอัปโหลดเว็บไซต์
- Full Package มีไฟล์เว็บและเครื่องมือหลังบ้านพร้อมชุดตรวจสอบ รัน `npm run check:v212` สำหรับการเปลี่ยนแปลงรอบนี้
