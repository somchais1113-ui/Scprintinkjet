# SCWork Inkjet V2.1 — เช็กราคา ภาษี และพิมพ์เอกสาร

ต่อยอดจาก Scprintinkjet.zip ที่ปรับภาพแล้ว ภาพทั้ง 6 ไฟล์ไม่ถูกบีบหรือเปลี่ยนเพิ่ม หน้าแรกและระบบติดตามงานคงเดิม เพิ่มเฉพาะส่วนสรุปยอดผู้ซื้อในหน้า Smart Quote กับกติกาก่อนแสดงราคาขาย

## ทดลองทันที

เปิด `smart-quote.html` เลือกบุคคลธรรมดา/นิติบุคคลไทยภาคเอกชน และเปิด “ทดลองคำนวณจากยอดที่กรอกเอง” ตัวอย่างคิดค่าบริการ 1,000 บาท ค่าเพิ่ม 0 บาท และ VAT 7% จะเห็นยอดเต็ม 1,070 บาท หากเป็นกรณีที่ต้องหัก ณ ที่จ่าย 3% จะเห็นภาษีหัก 30 บาท และยอดโอน 1,040 บาท ยอดตัวอย่างเป็นของเครื่องคิด ไม่เข้าสู่ใบประมาณราคา

ปุ่ม “พิมพ์สรุปสเปก / บันทึก PDF” ใช้งานได้โดยไม่มี LINE ใช้คำสั่ง Save as PDF ของหน้าพิมพ์เพื่อบันทึกไฟล์ เมื่อมีเรทและตั้งค่าจำหน่ายที่อนุมัติ ปุ่มเดียวกันจะพิมพ์ใบประมาณราคาพร้อมยอดแยกรายการ ชื่อผู้ขอราคาเป็นช่องทางเลือก ใช้ในหน้าพิมพ์บนอุปกรณ์ ไม่ส่งหรือเก็บบนเซิร์ฟเวอร์

## ตั้งค่าราคาจริง (Full Package)

1. ตรวจสถานะ VAT จริงของผู้ขายแล้วตั้ง `vatStatus` ใน `config/billing-config.js` เป็น `registered` หรือ `not-registered` ตรวจเรทขายจาก Pricing Master และนำไฟล์ Export มาใส่ที่ `data/pricing-public-data.js` ถ้าจด VAT เรทที่อนุมัติต้องเป็นอัตราบวกที่ถูกต้องสำหรับรายการ ถ้าไม่ได้จด VAT เรทต้องตั้งเป็น 0 หากตั้งไม่ตรงหรือยังไม่ยืนยัน เว็บจะไม่แสดงยอดราคาขาย
2. `managementFee` เป็นค่าบริหารที่เรียกเก็บจากลูกค้าเพิ่มเติมเท่านั้น ตั้ง `none` (ไม่มีค่าเพิ่ม), `fixed` (บาทต่อออเดอร์) หรือ `percent` (เปอร์เซ็นต์จากราคางานก่อน VAT) อย่าใส่ซ้ำถ้ารวมอยู่ในเรทแล้ว สูตรนี้ถือว่าค่าบริหารเป็นส่วนของธุรกรรมเดียวกัน หากเป็นการเรียกเก็บคนละฐาน ให้ประเมินแยกก่อนเสนอราคา
3. `standardOrder` ตั้ง `goods`, `service` หรือ `review` ตามที่ผู้รับผิดชอบบัญชียืนยันกับลักษณะงานจริง ผู้ซื้อเลือกสถานะผู้ซื้อเอง แต่เปลี่ยนประเภทภาษีของงานที่ร้านตั้งไว้ไม่ได้ ค่าเริ่มต้น `review` จะแสดงยอดเต็มเมื่อราคาและ VAT พร้อม โดยไม่ยืนยันยอดโอนหลังหักสำหรับนิติบุคคล
4. การคำนวณหัก 3% ในเวอร์ชันนี้ทำเฉพาะตัวอย่างทั่วไปของนิติบุคคลไทยเอกชนจ่ายค่าบริการ/จ้างทำของที่เข้าเกณฑ์ โดยคิดจากฐานก่อน VAT เมื่อสัญญาทั้งฉบับตั้งแต่ 1,000 บาท แม้ยอดชำระบางส่วนต่ำกว่า 1,000 บาท สำหรับรายการผสม หน่วยงานรัฐ ภาษีต่างประเทศ หรืออัตราเฉพาะ ให้เลือกให้ทีมตรวจสอบ ไม่ใช้ตารางนี้ยื่นภาษี
5. สร้างชุด Public ใหม่ด้วย `node qa/build-public-v210.mjs ชื่อโฟลเดอร์ใหม่` แล้วเผยแพร่เฉพาะ Public หลังตรวจ เปิดหน้าพิมพ์จริงบนมือถือและเดสก์ท็อปก่อนใช้งานกับลูกค้า

ใน ZIP นี้ยังไม่มีเรทขายที่อนุมัติหรือสถานะจด VAT ที่ยืนยัน จึงไม่แสดงราคาขายจริง ไม่เก็บเงิน ไม่จองเลขเอกสารบัญชี ไม่ออกใบแจ้งหนี้ ใบเสร็จ หรือใบกำกับภาษี หากจะออกเอกสารบัญชีจริงจากหน้าเว็บ ต้องเลือกใช้ระบบออกเอกสารของบริษัทและข้อมูลผู้ขายที่ตรวจสอบแล้วแยกจากการคำนวณนี้

เอกสารอ้างอิงจากกรมสรรพากร

- https://www.rd.go.th/25090.html และ https://www.rd.go.th/43063.html — ข้อแตกต่างระหว่างขายสติกเกอร์กับรับจ้างพิมพ์ตามข้อเท็จจริง
- https://www.rd.go.th/3479.html — ท.ป.4/2528 ข้อ 8 และ 12/7
- https://interweb1.rd.go.th/publish/seminar/training/RD06.pdf — การหัก ณ ที่จ่ายจากฐานก่อน VAT
- https://www.rd.go.th/5208.html — ผู้มีสิทธิและรายการสำคัญของใบกำกับภาษี
