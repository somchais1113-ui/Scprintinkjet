# SCWork Inkjet Sticker V2.1.11

แตก ZIP แล้วเปิด `index.html` เพื่อดูหน้าแรก จากนั้นกดที่แถบจุดเด่นใต้เมนูเพื่อเข้าสู่หน้ารายละเอียดในแท็บเดิม แต่ละหน้ามีลิงก์กลับหน้าแรกและลิงก์ไปหัวข้ออื่น

| หัวข้อ | ไฟล์ |
| --- | --- |
| ราคามาตรฐาน | `standard-pricing.html` |
| บริการออกแบบ | `design-services.html` |
| จัดส่งรวดเร็วและตรงเวลา | `delivery.html` |
| มีการชำระแบบเครดิตเทอม | `credit-terms.html` |

หน้ารายละเอียดใช้ภาษาไทยและอังกฤษตามที่เลือกบนหน้าแรก และมีปุ่มสลับภาษาในแต่ละหน้า ปุ่มขอราคาหรือสอบถามใช้หน้าเช็กราคาเดิม ปุ่มติดตามงานใช้หน้าติดตามเดิม

แถบด้านบน รูปภาพ แบนเนอร์ ฟอนต์ และการเลื่อนข้อความหน้าแรกใช้เวอร์ชันเดิม สูตรคำนวณราคา การตั้งค่าธุรกิจและหน้าที่มีอยู่ไม่เปลี่ยน

- ตรวจด้วย `npm run check:v2111`
- สร้างเฉพาะไฟล์สาธารณะด้วย `npm run build:public -- ./public-release` โดยระบุโฟลเดอร์ใหม่ จึงค่อยนำโฟลเดอร์นั้นไปใช้ขึ้นเว็บ
