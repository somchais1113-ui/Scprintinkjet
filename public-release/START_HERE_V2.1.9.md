# SCWork V2.1.9

เพิ่มแถบจุดเด่นถัดจากเมนูและก่อนแบนเนอร์หน้าแรก ไอคอนและสีอิงโทน SCWork แสดง 4 คอลัมน์บนจอกว้างและ 2 คอลัมน์บนมือถือ

- ราคามาตรฐาน
- บริการออกแบบ
- จัดส่งรวดเร็วและตรงเวลา
- มีการชำระแบบเครดิตเทอม

กดลูกศรด้านล่างเพื่อดูข้อความเรื่องจัดส่ง การตรวจไฟล์และออกแบบ และเงื่อนไขเครดิตเทอม แถบรองรับไทยและอังกฤษ และไม่เลื่อนข้อความเอง

## ตั้งค่าเมื่อมีข้อมูลจริง

เปิด `config/public-config.js` ดูรายการ `SCWORK_PUBLIC_BENEFITS`

- `reviewScore` และ `reviewCount` เป็นตัวเลขจริงของ SCWork คะแนน 0–5 และจำนวนรีวิวมากกว่า 0 ถ้าไม่ใส่ครบจะซ่อนการ์ดรีวิว
- `deliveryNoticeTh` และ `deliveryNoticeEn` เป็นข้อความเงื่อนไขการจัดส่งของ SCWork ที่ต้องการให้แสดงเป็นข้อความแรก หากเว้นว่างจะใช้ข้อความสอบถามกำหนดจัดส่ง โดยไม่สัญญาว่าส่งฟรีหรือส่งภายในเวลาตายตัว

ฟอนต์และแบนเนอร์เดิม ภาพวัสดุ แถบล่างและระบบเช็กราคาไม่เปลี่ยน ใช้ `npm run check:v219` เพื่อตรวจแถบใหม่ หรือ `npm run build:public` เพื่อสร้างชุดขึ้นเว็บ
