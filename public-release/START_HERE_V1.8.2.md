# SCWork Inkjet V1.8.2 — Phase 02 / ขอราคาและส่งสเปก

เพิ่มเฉพาะเส้นทางเช็กราคาและส่งสเปก หน้าแรก ภาพ Render และส่วนแสดงตัวอย่างแบบตรวจจาก Phase 01 คงเดิม

## เปิดทดสอบ

แตก ZIP แล้วเปิด Terminal ในโฟลเดอร์เดียวกับ `index.html` รัน `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000/product-labels.html` หรือ `http://localhost:8000/smart-quote.html?category=label` ใช้เมนูภาษาเพื่อทดสอบ TH/EN

## ขอบเขตของราคาที่เว็บคำนวณ

- ฉลากสินค้า PP ขาว ขนาด 5 × 5 ซม. ตัดมาตรฐาน ไม่มีบริการเสริม และเลือก 100, 500 หรือ 1,000 ดวง
- เมื่อไฟล์เรทได้รับการอนุมัติและคำนวณครบทั้งสามจำนวน หน้า Smart Quote แสดงยอดรวมและราคาเฉลี่ยต่อดวง พร้อมแจ้งว่าใช้ VAT ตามเรทที่ตั้งไว้หรือไม่ได้คิด VAT และไม่รวมค่าส่ง
- คิดจากกติกาจำนวนแผ่น A3+ และขั้นต่ำที่ตั้งในเรทขาย ไม่ปรับยอดให้ดูต่างกันโดยฝืนสูตร หากขั้นต่ำทำให้สองยอดเท่ากันจะแสดงตามจริง
- ลูกค้ายังระบุขนาด จำนวน วัสดุ งานไดคัท หรือบริการเสริมอื่นได้ ระบบสรุปสเปกเพื่อให้ทีมประเมิน ไม่สรุปราคาอัตโนมัติ และไม่ต้องสมัครสมาชิกหรืออัปโหลดไฟล์

## เปิดราคาและ LINE OA จริง

1. ใน Full Package เปิด Pricing Master ตามคู่มือ `START_HERE_V1.7.5.md` ตรวจพื้นที่แผ่น ระยะเผื่อ ขั้นต่ำ ราคา และ VAT ตามที่ร้านใช้ ตรวจยอดทั้งสามจำนวน แล้วอนุมัติเฉพาะ PP ขาวสำหรับระยะนี้
2. ส่งออกไฟล์ราคาขายจาก Pricing Master มาแทน `data/pricing-public-data.js` **ห้ามนำไฟล์ Demo หรือต้นทุน/แบ็กอัปส่วนตัวไปแทนไฟล์นี้** เวอร์ชันเรทในไฟล์ถูกแสดงในสรุปพร้อมส่งต่อเข้า LINE
3. ใส่ LINE OA ของ SCWork ใน `config/public-config.js` ช่อง `lineId` เป็น ID ของบัญชีขึ้นต้นด้วย `@` หรือลิงก์แบบเต็มที่มี ID เช่น `https://line.me/R/ti/p/%40yourname` ใน `lineUrl` โดยเปลี่ยนเป็นบัญชีจริงก่อนใช้
4. ตรวจด้วย `npm run check:launch` ใน Full Package เครื่องมือนี้ตรวจว่าเรทคำนวณได้ครบและมี ID ที่ใช้ใส่ข้อความร่าง ไม่ได้ทดสอบการส่งข้อความหรือยืนยันเจ้าของบัญชี ควรลองเปิด LINE บนมือถือจริงและเช็กชื่อร้านก่อนเผยแพร่
5. สร้างชุด Public ใหม่ด้วย `node qa/build-public-v182.mjs ชื่อโฟลเดอร์ใหม่` แล้วเผยแพร่เฉพาะชุด Public หลังตรวจ ไม่เผยแพร่เครื่องมือ Pricing Master หรือ Full Package

เมื่อมี ID ปุ่ม LINE จะเปิดห้องแชตพร้อมร่างสเปก ลูกค้าตรวจแล้วกดส่งเอง หากมีแต่ลิงก์สั้น `lin.ee` หรือข้อความยาวเกินช่วงที่เว็บใช้เปิดร่าง ให้คัดลอกแล้ววางในแชต ไม่ต้องกรอกสเปกใหม่ รายละเอียด LINE URL scheme ดูได้ที่ [LINE Developers](https://developers.line.biz/en/docs/line-login/using-line-url-scheme/#sending-text-messages-to-a-line-official-account).

## สถานะ ZIP ที่ส่ง

เรทขายในชุดนี้ยังว่างและยังไม่ได้ใส่ LINE OA จริง จึงไม่มีราคาหรือปุ่ม LINE ปลอมบนหน้าลูกค้า สามารถเลือกและคัดลอกสเปกได้แล้ว ส่วนหน้า Landing จะใช้ปุ่ม “ส่งสเปกเพื่อขอราคา” จนกว่าจะมีเรทที่ผ่านเงื่อนไข ทั้งสองชุดยังไม่ได้เผยแพร่
