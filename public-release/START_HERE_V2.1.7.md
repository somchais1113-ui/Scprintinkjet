# SCWork V2.1.7

ปรับภาพบนหน้าแรก 3 ส่วน โดยคงข้อความ โครงหน้า และระบบเช็กราคาเดิม

## ภาพเปรียบเทียบวัสดุ

วัสดุทั้ง 5 แบบใช้โลโก้จากเวกเตอร์ต้นฉบับเดียวกัน ล็อกขนาด สี และตำแหน่งบนกรอบ 1:1 เหมือนกันทุกภาพ ทั้งในภาพการ์ดและหน้าขยาย ไม่ได้ให้ระบบสร้างรูปทรงโลโก้แยกทีละภาพ

- WebP 800 × 800 px พร้อมภาพ 400 × 400 px สำหรับจอเล็ก อยู่ใน `assets/images/materials/`
- PNG ความละเอียดสูงและเวกเตอร์ต้นฉบับ `swatch-mark.svg` อยู่ใน `assets/images/source/materials/`

## ภาพบริการ

- ฉลากสินค้าและบรรจุภัณฑ์ — ขวดแก้วและกล่องที่เห็นการติดฉลากชัด
- สติกเกอร์ไดคัทตามรูปทรง — ขอบตัดรอบคาแรกเตอร์และตัวอย่างที่ลอกออกจากแผ่น
- สติกเกอร์ติดร้านและกระจก — ตัวอย่างไวนิลบนกระจกร้าน

## ภาพขั้นตอนผลิต

- 01 ตรวจสอบไฟล์ — พรูฟพิมพ์ เส้นตัดตก และการตรวจขนาด
- 02 เลือกวัสดุและงานพิมพ์ — ตัวอย่างวัสดุคู่กับกระบวนการพิมพ์
- 03 งานหลังพิมพ์และส่งมอบ — ตรวจชิ้นงานไดคัทและเตรียมแพ็ก

ภาพใหม่ใช้สไตล์ภาพถ่ายจำลอง ไฟล์ต้นฉบับภาพบริการและขั้นตอนผลิตอยู่ใน `assets/images/source/home-photography/` ภาพสำหรับเว็บเป็น WebP แยกตามหัวข้อ ไม่ใช่ภาพรวมหลายช่อง

## เปิดและตรวจ

เปิดเว็บจากโฟลเดอร์ที่แตก ZIP ด้วย `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000/` ใช้ `npm run check:v217` ตรวจไฟล์ภาพใหม่ หรือใช้ `npm run build:public` สร้างชุดลงเว็บ
