# SCWork Inkjet Sticker — V2.1.12

เวอร์ชันนี้ต่อจาก **V2.1.11** โดยปรับเฉพาะหน้าแรกและตัวเลือกประเภทงานในหน้าเช็กราคา

## เปลี่ยนอะไรบ้าง

1. `index.html`: แบนเนอร์หลักทั้ง 4 สไลด์ใช้กรอบกว้าง **ไม่เกิน 1170px** ซึ่งเท่ากับ `.container` ของเว็บ; กึ่งกลางจอ มีการครอปภาพสม่ำเสมอและปรับตามมือถือ พร้อมรักษาพื้นที่อ่านข้อความด้านซ้าย
2. เอาแถบ **“อัปเดตบริการ / Service updates”** และปุ่มเลื่อนข้อความออกจากหน้าแรกแล้ว แต่ยังคงแถบ 4 หัวข้อด้านบน พร้อมลิงก์หน้ารายละเอียดทุกหัวข้อ และการแปล TH/EN
3. `smart-quote.html`: เปลี่ยนการ์ดเลือกฉลากสินค้า / ไดคัท / งานขนาดใหญ่ เป็นภาพคมชัดแยกตามงาน, ปรับ Crop, กรอบเลือก และขนาดชื่อให้ชัดขึ้น บนมือถือเป็นแถวเลื่อนแนวนอนเพื่อลดการบีบภาพ
4. **ไม่มีการปรับสูตรราคา** ภาษี ใบสรุป หรือข้อมูลภายใน และไม่มีการเปลี่ยนภาพ HERO 4 ไฟล์เดิม

## เปลี่ยนรูปประเภทงานเองภายหลัง

ภาพเว็บ:
- `assets/images/quote-choices/quote-product-labels.webp`
- `assets/images/quote-choices/quote-diecut-stickers.webp`
- `assets/images/quote-choices/quote-large-format.webp`

ภาพ PNG ต้นฉบับสำหรับปรับงานอยู่ใน Full Package ที่
`assets/images/source/quote-choices/`

ภาพใหม่เป็น **ภาพจำลองประกอบประเภทงาน** ไม่ใช่ภาพผลงานลูกค้า ควรเปลี่ยนเป็นภาพถ่ายสินค้าจริงที่ได้รับอนุญาตก่อนนำไปใช้เป็นผลงานอ้างอิง

หากเปลี่ยนชื่อไฟล์หรือโฟลเดอร์ ต้องแก้ `smart-quote.html` ในบล็อก `#quoteTypes` ด้วย

## การเปิดเว็บ

- เปิด `index.html` เพื่อดูหน้าแรก
- เปิด `smart-quote.html` เพื่อดูตัวเลือกสติกเกอร์และลองสลับการ์ดทั้ง 3 แบบ
- แนะนำทดสอบผ่าน local HTTP server หรือ hosting ที่รองรับ static HTML

## การตรวจสอบ

```bash
npm run check:v2112
npm run check:v210
npm run check:v215
npm run check:v218
npm run build:public -- ./public-release
```
