# Client Logos — SCWORK

This directory is empty on purpose. The website displays clearly-labeled placeholder slots until approved customer logos are supplied. Do not portray demonstration logos as endorsements.

Steps:
1. Obtain permission from the brand/company to show its logo publicly.
2. Place its raster or SVG logo in this folder. Optimize the file for web use.
3. Edit `data/client-logos.js`: fill in `name`, set `src` to `./assets/images/client-logos/<filename>` and `approved: true`.
4. Preview Desktop/Mobile and verify legibility in grayscale.
5. Deploy updated assets and client-logos.js together.
