# SCWork V2.1.45 — image-led Brand Packages

Based on V2.1.44. Homepage Brand Development cards now share the open, rounded-image visual language of the preceding sticker service cards. Three equal desktop columns, larger images, navy titles, compact left-aligned orange CTAs, and a warm orange image outline and recommendation badge on the middle card. Tablet layout uses image/text rows; mobile stacks each image above the copy.

The package copy, CTA destinations, comparison table and recommended package remain unchanged. The previous split heading, removal of Additional Services and legacy standalone pricing CTA are retained. No pricing, database or admin logic was changed.

Build the deploy-only folder with `npm run build:public -- /path/to/new-output-folder`. The included public-release folder is a freshly built copy.

Also corrected inherited split-header contrast and removed the narrow heading width limit, without changing the copy.
